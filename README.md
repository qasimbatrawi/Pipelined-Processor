# Computer Architecture Project

## Project Overview
This project implements and verifies a **pipelined 16-bit RISC processor** in **Verilog**.  
The processor follows a **5-stage pipeline**:
1. Instruction Fetch (IF)  
2. Instruction Decode (ID)  
3. Execute (EX)  
4. Memory Access (MEM)  
5. Write Back (WB)  

The design supports some RISC-style instructions and has performance monitoring registers.
Verification is done through simulation using test programs.
